Los Bots

Dos asistentes inteligentes que resuelven problemas reales, todos corriendo sobre la misma infraestructura.

⚡

SalchipapaBot

@salchipapa_593_bot

Consulta de medidores eléctricos del Consorcio ART (Ecuador). Busca por cuadrilla, número de serie, trámite o solicitud en lenguaje natural. Incluye transcripción de voz con Groq Whisper y coordenadas GPS del portal ACIIS y enlaces a Google Maps.

DeepSeek IA Groq Whisper SQLite python-telegram-bot Scraper SAP 🕷️
🧠

Hermes Agent

@HermesAgent · Asistente personal

Agente de IA autónomo que gestiona correos electrónicos (resúmenes automáticos cada hora con Himalaya), consulta y analiza la base de datos de medidores, responde correos, y automatiza tareas complejas por voz o texto. El cerebro del ecosistema.

Hermes AI DeepSeek v4 Flash Himalaya CLI SQLite Cron Jobs
⚡ Capacidades

Lo que Hemos Logrado

Automatizaciones, integraciones y soluciones que ya están en producción.

📧

Gestión Automática de Correos

Resúmenes inteligentes de la bandeja de entrada cada hora vía cron job. Responde correos automáticamente con información actualizada de la base de datos.

Himalaya + Cron
🗄️

Consultas SQL en Lenguaje Natural

Más de 375,000 registros en 8 tablas. Carga de archivos XLSX a SQLite, consultas por voz o texto, análisis por cuadrilla y reportes diarios.

SQLite + DeepSeek
🎤

Transcripción de Voz a Acción

Groq Whisper transforma audios en texto y el agente ejecuta la acción sin intervención manual. Preguntas, respuestas y automatización por voz.

Groq Whisper + IA
🤖

IA Híbrida Cloud + Local

DeepSeek v4 Flash en la nube para tareas complejas y Llama 3.2 1B local en la tablet para respuestas rápidas sin depender de internet, más modelo de razonamiento DeepSeek-R1 para análisis profundos.

DeepSeek + Llama 3.2
📊

Análisis de Datos en Tiempo Real

Consultas dinámicas a la base de datos de medidores: filtros por cuadrilla, tipo de solicitud, fechas, coordenadas GPS y más. Reportes al instante.

SQL + Pandas
🔄

Automatización de Procesos

Carga automática de XLSX a SQLite, respuestas programadas a correos, resúmenes periódicos, y tareas de mantenimiento automatizadas con cron y scripts.

Cron + Scripts
🌐

Infraestructura Web Propia

Servidor web publicado por túnel Cloudflare con HTTPS: dashboard de monitoreo, página del ecosistema y acceso remoto. Todo servido desde la tablet, sin hosting contratado.

Cloudflare Tunnel
📊

Monitoreo en Vivo del Servidor

Endpoint /api/system que reporta CPU, RAM, disco, uptime del dispositivo y el estado de cada servicio en tiempo real, verificando que el PID esté vivo.

API + Dashboard
💾

Respaldos Automáticos a Telegram

Respaldo periódico de la base de datos enviado directo al chat, sin OAuth ni servicios de terceros. Recuperación ante cualquier desastre.

Cron + Telegram API
🔄

Auto-Recuperación de Servicios

Cada servicio corre bajo runsv: si un proceso se cae, se levanta solo. Supervisión real con reinicio automático y rotación de logs.

runit + runsv

Cuestionarios Médicos con IA

Generador de evaluaciones interactivas de opción múltiple por área temática, con retroalimentación instantánea y preguntas creadas por IA.

DeepSeek IA

Mantenimiento Automotriz Multi-Vehículo
